# celtium-site

The official project site for [Celtium](https://github.com/souta-lab/celtium) — a native Vulkan renderer
for Minecraft 1.12.2 on CleanroomMC.

**Live:** https://souta-lab.github.io/celtium-site/

Hand-written static HTML/CSS/JS (no framework, no build step), deployed with GitHub Pages from this
repository's `main` branch. Gallery frames are real captures from the project's verification legs.

To preview locally, serve the repository root with any static file server, e.g.:

```sh
python3 -m http.server 8000
```
